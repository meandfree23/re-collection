미국 건축 스튜디오 데사이 치아 아키텍처(Desai Chia Architecture)가 뉴욕 채텀의 80에이커 사유지 내 습지에 야생 동물 관찰용 파빌리온을 설계했다. 35제곱미터 규모의 이 구조물은 숫자 8을 닮은 평면 위에 교차하는 원통형 지붕을 얹어 습지의 파동을 형상화했다. 지면을 띄운 기초 설계로 습지 생태계 교란을 최소화했다.

자연의 유기적 현상인 물의 파동을 금속이라는 차가운 재료로 고정해, 습지라는 생태적 맥락 속에 기하학적 조형미를 삽입했다.
