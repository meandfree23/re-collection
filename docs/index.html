로스앤젤레스 기반의 프레임48(Frame48)은 팻 브레인 토이즈(Fat Brain Toys)의 에어 튜브즈(Air Toobz) 제품을 위한 CG 광고를 제작했다. 제작진은 제품의 실제 조립 제약 조건을 반영한 커스텀 후디니 툴을 개발하여 수많은 구성 조합을 빠르게 시뮬레이션했다. 이를 통해 반복적인 조립 업무를 자동화하고 장난감의 유희적 움직임을 구현하는 데 집중했다.

제품의 물리적 조립 규칙을 코드로 치환해 무한한 조합 가능성을 시각적 유희로 전환했다.
