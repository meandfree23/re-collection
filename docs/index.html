벙커 너머의 설계: 생존주의 건축이 제안하는 일상의 회복탄력성

미국 정부가 1959년 발행한 '가족 낙진 대피소' 매뉴얼을 기점으로, 생존주의 건축은 냉전 시대의 폐쇄적 벙커에서 현대의 유연한 인프라로 진화했다. 라파엘 코지는 주거 공간을 단순한 소유물이 아닌 외부 시스템 단절 시에도 기본 기능을 유지하는 독립적 인프라로 정의하며, 중복 설계를 통한 회복탄력성을 강조한다.

거주 공간을 외부 네트워크에 완전히 의존하는 대상이 아닌, 비상 시에도 최소한의 기능을 수행하는 자립적 인프라로 재정의한다.
