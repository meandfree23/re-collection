영국의 건축 매거진 디 아키텍처럴 리뷰(The Architectural Review)는 1896년부터 독립적이고 비판적인 시선으로 도시와 건축의 지형을 탐구해 왔다. 본문은 로그인 유도 화면과 매거진 소개문으로 구성되어 있으며 소렌 필만(Søren Pihlmann)의 구체적인 작업 내용은 확인되지 않는다.

매거진의 아카이브 안내문만 노출되어 구체적인 건축적 장치나 물성을 확인할 수 없다.

왜 지금
건축 비평 매체가 오랜 기간 축적해 온 아카이브의 구조와 접근 방식을 환기한다.
작동 방식
웹사이트의 로그인과 회원가입 유도 레이아웃이 콘텐츠 접근을 제한하는 장치로 작동한다.
감각과 물성
디지털 화면 속 텍스트와 로그인 인터페이스 외에 시각적이거나 물성적인 자극은 부재한다.
계보·맥락
1896년 창간된 디 아키텍처럴 리뷰는 도시와 조경, 인테리어 디자인을 아우르는 국제 건축 매거진이다.
연출로 가져갈 것
공간이나 영상 연출에 직접 적용할 수 있는 구체적인 물성이나 동선 데이터는 존재하지 않는다.
